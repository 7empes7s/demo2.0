## 2026-10-06: Booth v1 protocol core (non-binding, unaudited)

Lesson: `lessons/2026-10-06-booth-ballot-replay.md`. Merged origin/main.
- Done: `modules/booth` (`d2-booth`, AGPL, Rust, unaudited, non-binding): k-of-n guardian key by joint Feldman VSS (ristretto255, `curve25519-dalek` 4.1.3, Schnorr proof of each constant term, `run_dkg` passes shares in memory for tests); exponential ElGamal ballots, one ciphertext per option, disjunctive Chaum-Pedersen 0-or-1 proofs and a sum-to-one proof, Fiat-Shamir over `merlin` 3 transcripts bound to the round id and the pseudonym, Ed25519 signature by the voter's round key registered at sign-up; hash-chained board (`SHA-256` over seq, prev, kind and canonical JSON); last valid ballot per pseudonym counts; homomorphic aggregate, guardians' partial decryptions with Chaum-Pedersen proofs, Lagrange combination, counts by discrete log; `verify_board` replays the board from entry 0 (strict: any invalid entry fails the board; ballot proofs checked on all cores). CLI `d2-booth verify|demo|vectors|check`. `spec/booth/README.md` (wire format for an independent verifier) and `spec/booth/vectors.json` (a deterministic 24-entry round plus 24 must-fail mutations (29 after the review fixes) with the error code each must give; drift test compares byte for byte).
- Acceptance (Phase 3, as far as v1 goes): `tests/acceptance.rs`. Re-vote test: a coerced vote then a private re-vote gives the same tally as the no-coercion board and the coerced option is not counted; the test also asserts exactly what the board reveals (one more ballot than sign-ups, and two ballots under the voter's pseudonym). 10,000-ballot election (5 guardians, 3 of them decrypt, 104 re-votes) tallied and verified from a JSON round trip of the board alone, about 18 s in check.sh on 4 cores.

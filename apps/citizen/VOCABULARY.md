# Vocabulary

Use one word per role, and use it everywhere: in the UI, the docs and the prompts.

| Use | Not | Why |
|---|---|---|
| file | dossier, bill (when the type is unknown), item | A Chamber "dossier" can be a bill, a debate or something else. "Bill" is used only when the type is a bill. |
| Companion | AI, bot, assistant, chatbot | One name for the explainer. |
| resident | citizen (in the UI), user, voter | Many people in Luxembourg can't vote nationally but are affected by the files. |
| official documents | sources (in headings), data | "Source N" is used only for the numbered citation. |
| where you stand | opinion, vote, position (in the UI) | Nothing the resident does in the app is a vote. |
| council vote | poll, result | Only for how Esch councillors voted on a point, as the city publishes it. |
| Chamber, Esch-sur-Alzette | parliament, city hall, municipality | The place label on each file. |
| point (of a council agenda) | item, motion | "Point 3" is the council's own numbering. |
| argue the other side | debate, convince, persuade | The Companion tests a view. It never pushes one. |
| supported, unclear, contradicted | true, false, fake, misleading | The grades say what the documents say, not what is true in the world. |
| quote found | verified, fact-checked, true | A found quote shows the words are in the document, not that the sentence is right. |

Never in the UI: recommend, should vote, best option, correct answer, raw ids (`lu.chd.8739`), model names, except in the small provenance line.

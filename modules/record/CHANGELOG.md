# Changelog

## 0.1.0

- RFC 9162 Merkle log in SQLite with O(log n) appends; inclusion and consistency proofs and their checks.
- Ed25519 checkpoints as C2SP signed notes; signed entries checked on append.
- Stdlib HTTP API, `d2-record` CLI, OpenTimestamps anchor, upgrade and verify.
- Shared vectors in `spec/record/vectors/` and a 1M-entry benchmark.
